## Mobile Application Architecture

Our mobile application architecture is defined and documented across two key repositories. These resources provide everything you need to understand our principles, whether you are starting a new project or contributing to an existing one.

### 1. Reference Implementation (Sportino)

This repository contains a demo application that showcases architectural principles in practice. It includes comprehensive documentation covering the implementation details and the reasoning behind architectural choices.

Go here to understand the architecture in a real-example context.

Link: https://github.com/infinum/android-sportino

### 2. Project Template

This is the official template for creating new Android application. It provides a pre-configured project with the entire architecture and module structure already in place, including a specific document on our modularization strategy.

Go here to start a new project.

Link: https://github.com/infinum/android-new-project-template
